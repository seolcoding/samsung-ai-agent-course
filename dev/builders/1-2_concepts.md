# 1-2 교안 노트북 — 2단계 개념·블록 설계 (v1, 2026-09-28)

1단계 목차: `1-2_outline.md`(v2). 여기서는 섹션마다 **노트북 블록(셀) 순서**를 정한다. 설명 셀 원고는 버전별 파일(`1-2_explain_A.md`, `_B.md`, `_C.md`)에 둔다.

## 블록 규칙

- **예시는 단계마다 블록을 나눈다.** 한 단계는 **설명 → 코드 → 볼 지점** 세 셀로 이루어진다.
  - [설명] 마크다운 셀. 이 단계에서 무엇을 보는지 쓴다. 버전별로 다르다.
  - [코드] 원본 파일에서 이 단계에 해당하는 구간만 화면에 보여 주고 실행한다. 원본 파일은 고치지 않는다.
  - [볼 지점] 마크다운 셀. 출력에서 어디를 볼지 쓴다. 세 버전이 같다.
- **단계 실행 도구**: `run_step(파일, 시작 표시, 끝 표시)`(3단계에서 `lessons/assets/`에 만든다)
  - 원본 파일에서 두 표시 사이의 줄을 읽어, 코드와 출력을 함께 보여 준다.
  - 같은 파일의 단계들은 변수를 이어서 쓴다(파일별로 하나의 이름공간을 둔다).
  - 원본의 한 줄도 바꾸지 않는다. 원본 전체를 한 번에 실행한 결과와 같다.
- 슬라이드는 `show_slides("1-2", [쪽])`, 코드 전체 구조는 `show_code_map`, 퀴즈는 `display_quiz`(객관식)와 `show_order_quiz`, 예측은 "예측 후 실행" 셀(예측 변수 → 실행 → 비교)을 쓴다.
- 숫자 정답은 코드로 계산한다. 실행 출력의 숫자는 "출력에서 읽기"로만 묻는다.
