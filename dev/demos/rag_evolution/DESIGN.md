# 설계

이 앱은 제품이 아니라 **실습 가이드이자 참고 견본**입니다. 수강생이 핵심을 한눈에 보고, 같은 것을 CodeMate로 만들어 비교하게 하는 것이 목적입니다. 그래서 첫 화면에는 핵심만 두고 세부는 접어 둡니다.

| 파일 | 책임 |
|---|---|
| `app.py` | 페이지 목록, 사이드바 실행 모드, 세션 기본값 |
| `app_pages/` | 한눈에 보기 + 단계별 페이지(각 한 줄짜리) |
| `lesson.py` | 화면의 모든 글: 바뀌는 것·이유·구조 그림·핵심 코드·지시문·성공 기준·예시 질문·심화 설명 |
| `ui.py` | 페이지 틀(써 보기·핵심 탭·심화), 실행 기록, 비교 화면 |
| `backend.py` | 단계 함수 `run_raw_llm` ~ `run_agentic`, 실제 실행(`run_live`), 녹화 재생(`run_replay`) |
| `graphs.py` | 5·8단계 그래프. 그림(`draw_mermaid`)과 실행이 같은 함수를 쓴다 |
| `tools.py` | 위키피디아·사진·합계 + (4·5단계) PDF 쪽 읽기(질문당 4쪽) 또는 (8단계) 보험 벡터 검색 |
| `runtime_config.py` | 모드별 설정, 사내 게이트웨이 헤더·임베딩 |
| `documents.py`, `data/` | PDF(쪽 단위), 녹화 파일 |

- 단계 함수는 `(질문, ctx)`를 받아(ctx = 설정·모델·문서 인덱스·이전 대화·checkpointer) 화면용 이벤트(step·token·sources·photo·review)를 내보냅니다. 심화의 "실제 실행 코드"는 이 함수의 소스를 그대로 보여 줍니다. 핵심 코드 탭은 학습용으로 줄인 코드입니다.
- LLM 호출 수는 콜백(`CallCounter`)으로 셉니다. 3단계 체인 안의 검색 결과도 콜백(`on_retriever_end`)으로 꺼냅니다.
- 순서는 "LLM의 한계 → 하나씩 메우기"입니다: 형식(2) → 기억(3) → 도구(4·5) → 문서(6·7) → 스스로 점검(8). 4·5단계는 검색 없이 PDF 쪽을 짐작해 읽다가 막히는 모습으로 6단계 RAG의 필요성을 보여 줍니다.
- 대화 기억: 1·2단계는 보내지 않음, 3·4·6·7·8단계는 화면의 이전 대화를 history로 다시 보냄, 5단계는 LangGraph checkpointer(thread_id)가 맡음. "대화 지우기"로 둘 다 초기화합니다.
- 7단계 Re-ranking·Query Rewrite는 JSON 응답을 정규식으로 꺼내고, 형식이 틀리면 한 번 더 묻고, 그래도 안 되면 RRF 순서로 대신하며 그 사실을 실행 기록에 남깁니다.
- 6~8단계는 같은 Chroma 인덱스를 씁니다. 인덱스는 공급자·모델·인증 지문·PDF 해시·청크 크기로 구분해 캐시합니다.
- 녹화 재생은 OpenAI 실제 실행의 이벤트를 그대로 저장했다가 다시 흘려보냅니다. 새 질문은 재생하지 않고 경고합니다.
- 대화 기록은 사용자 세션 안에서 실행 모드·연결별로 나눕니다.
- 1단계에서 모델이 적은 이미지 주소는 그림으로 그리지 않고 "확인 안 됨"으로 표시합니다. 사진은 4단계부터 도구가 가져온 것만 그립니다.
- 모델 검토는 정확성 점수가 아닙니다. 검토 통과·재작성 한도·형식 오류를 구분해 표시합니다.
