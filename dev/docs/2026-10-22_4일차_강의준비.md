# 4일차 강의 준비 (14차수, 2026-10-22)

## 4. 4-3 캡스톤: 이름 약속과 막힘 지점

**시작할 때 칠판에 적는다(이름 약속).** 정답 코드는 이 이름을 전제로 쓰여 있어, 맞춰 두어야 나중에 붙인 코드가 맞물린다.
- State 필드: `topic`, `research_result`, `draft`, `next`
- Agent 변수: `researcher`, `writer` · 도구 목록: `mcp_tools` · 그래프: `app`

| 단계 | 비었거나 틀리면 | 멈추는 범위 |
|---|---|---|
| 6.1 도구 | 오류 없이 `null`을 돌려주고 MCP 문서만으로 끝까지 감(조용히 틀림) | 없음 |
| 6.2 State | `KeyError: 'topic'` 또는 Researcher 무한 반복 | 전부 |
| 6.3 MCP·Agent | `ConnectError`, NameError. skill 경로가 틀리면 오류 없이 양식만 무시 | 전부 |
| 6.4 노드 | `KeyError: ''`, 결과를 State에 안 돌려주면 무한 반복 | 전부(6.6 뒤에야 드러남) |
| 6.5 그래프·승인 | `No checkpointer set`, 중단 설정이 없으면 y/n 전에 Writer가 돌아 버림 | 6.6 이후 |
| 6.6 실행 | ⚠️ 줄만 나오고 끝 | 6.1~6.5를 실행으로 확인할 수 없음 |
| 6.7 평가 | `'NoneType' … 'relevance'` | 점수만 |

- **가장 큰 위험:** 6.6 전에는 실행으로 확인되는 곳이 6.3 뒤(`MCP 도구 로드`) 하나뿐이다. 6.2·6.4·6.5의 실수가 3시간째 첫 전체 실행에서 한꺼번에 터진다.
- **어려운 순서(판단):** 6.4(약 40줄, async·구조화 출력·Langfuse 한꺼번에) > 6.3(사내 모델이 deepagents API를 모를 수 있음) > 6.6(2-1 예제는 동기 `invoke`라 그대로 베끼면 `No synchronous function provided`).
- **6.1 중간 확인(자료 밖 제안, 사외에서만 확인):**
  `uv run python -c "import sys; sys.path.insert(0,'course/Chapter02/capstone'); import starter; print(starter.search_web.invoke('AI')); print(starter.rag_search.invoke('AI'))"` → `None`이면 `return`이 빠진 것.
- **어디서 배웠는지 AI에게 같이 보여 주게 한다:** 6.1 → 1-4 RAG LAB·`course/agent_docs/ragaas.md`, 6.2·6.4 → 2-2 Multi-Agent LAB, 6.3 → 3-2 MCP·4-1 Harness LAB, 6.5·6.6 → 2-1 LangGraph LAB 5·6장, 6.7 → 4-2 LAB.
- 사내 RAGaaS 기본 인덱스는 펫보험 약관이라 `rag_search` 결과가 주제와 무관해도 정상이다.

**묶음 공개를 추천하는 이유(정할 것 1):**
- 정답이 없으면 앞 단계에서 막힌 사람은 뒤로 못 간다. 4시간 중 남은 시간이 통째로 사라진다.
- 강사 화면 공개는 받아 적게 되어 "직접 치지 않는다"는 전제와 어긋나고, 1:1 지원은 강사 혼자 감당이 안 된다.
- 채팅으로 붙여 주고 "이 코드를 해당 자리에 넣고 내 코드와 다른 점만 설명해 줘"라고 시키면 검토·재지시 목표도 지킨다.
- 정답 셀은 `main()` 안 4칸 들여쓰기다. 채팅이 앞 공백을 지울 수 있으니(짐작) 직접 붙이지 말고 AI에게 넣게 한다.
- 단계별 정답은 강사본 `dev/instructor/Chapter02/4-3_capstone_LAB.ipynb` 6장 각 단계의 접힌 "정답 보기"에 있다(수강생본에는 없음). 전체 정답은 같은 노트북 8.2.

**시연 동선(0:10).** 터미널 출력만 보여 주고 `solution.py` 파일은 열지 않는다. 화면은 크게.
1. 터미널 A `uv run python course/Chapter02/capstone/mcp_server.py`, 터미널 B `uv run python course/Chapter02/capstone/solution.py`.
   - `MCP 도구 로드`가 나오면 "6.3에서 만들 줄"이라고 짚는다.
   - `## 리서치 결과:`가 나오면 Researcher 스킬의 양식이라고 짚는다.
2. `(y/n)`에서 멈추면 "이 자료로 보고서를 써도 될까요?"라고 묻는다. 비용이 드는 다음 단계 전에 사람이 멈춘다는 HITL의 뜻을 여기서 보여 준다. 그다음 `y`.
3. `[DS-AI-RPT v2.1]` 보고서 → 네 항목 막대 → `종합 점수`(사외 0.90~0.95, 실행마다 다름).
4. Langfuse에서 방금 시각 trace 3개: `LangGraph`(Researcher, 도구 호출), `LangGraph`(Writer, 스킬 읽기), `RunnableSequence`(Judge, Scores 4개). Supervisor는 trace가 없다.
5. `n` 실행(약 25초)은 6.6을 시작할 때 보여 줘도 된다.

> `solution.py`는 git에 없는 파일이다. 수업에 쓰는 PC가 이 Mac이 아니면, 그 PC에서 강사본 LAB 8.2 셀(`%%writefile ../capstone/solution.py`)을 한 번 실행해 새로 만든다.
