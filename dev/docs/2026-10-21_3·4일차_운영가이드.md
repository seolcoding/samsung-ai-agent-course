## 수강생 받기 (3일차 첫 10분)

- 처음 받는 사람: `git clone -b study --single-branch https://github.com/seolcoding/samsung-ai-agent-course.git`
  → `cd samsung-ai-agent-course` → `.env.sample`을 `.env`로 복사(Windows `copy .env.sample .env`, 맥 `cp .env.sample .env`)
  → `.env`에 1일차와 같은 사내 값(`COURSE_ENV=samsung` 등) 채우기 → VS Code에서 이 폴더 열기.
- 1·2일차에 받은 사람: 저장소 폴더에서 `git pull`
  - 노트북을 실행해 저장했다면 pull이 막힌다 → `git stash` 후 다시 `git pull`(출력만 치운다).
- 모두: `uv sync` → VS Code에서 노트북 커널 `.venv` 선택.
- `.env`에 두 줄 추가: `DART_API_KEY=`(강사가 칠판·채팅으로 알려 줌), `TAVILY_API_KEY=`(각자 app.tavily.com 가입, 3-1 시간에 미리).
- 확인: `uv run python -m config.check --mcp --live` → "준비 완료". `.env`를 고쳤으면 **커널 다시 시작**.
