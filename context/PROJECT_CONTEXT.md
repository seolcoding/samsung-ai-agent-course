## 교육 목적과 일정

기존 SW 개발자의 AI Application 개발 역량 전환·향상이 목표다. 명목상 Python 기초 프로그래밍과 LLM 기본 이론을 아는 수준을 전제하지만, 실제 교육에서는 비개발자부터 자체 MCP 서버 운영 경험자까지 수준 차이가 크다. [8/28 최초 제안](https://mail.google.com/mail/u/0/#all/1a046fd41a4b05ff)

| 12차수 | 2026-09-14~09-17 | 08:30~17:30 | 기존 운영 일정. 9월은 장금상선 일정과 일부 겹쳐 10월 우선 제안 |

점심 1시간을 제외해 하루 8시간이다. M1은 월·화 16시간, M2는 수·목 16시간이다. 10월 두 차수 합계는 이 일정으로 계산하면 8일·64시간이다. 별도의 계약서, 강사료, 교통·숙박 지원 조건은 수집 자료에서 확인되지 않았다.

M1은 LangChain·LangGraph 기반 AI Agent 챗봇 개발 입문 과정, M2는 MCP·A2A·Harness 기반 Multi-Agent 심화 과정이다. M2는 M1 이수 또는 유사 경험을 전제로 하지만 실제로 M1 미수강자가 들어와 격차가 생겼다는 운영 피드백이 있다.

## 기존 자료의 위치 안내

README에는 교육 페이지를 `/go/ai-pd`로 안내한다. 상대 경로만 있어 외부에서 접속할 수 있는 전체 URL과 도메인은 확인되지 않았다. 사내 교육용 GitHub 저장소 주소도 전달된 첨부에 없다.

안내문이 가리키는 폴더는 다음과 같다. 이 폴더 자체나 구현 코드는 이번 메일에 첨부되지 않았다.

- `강의안_최종수정본`: 현재 강의안.
- `강의안_최종수정본_축약버전`: 현재 강의안의 축약본.
- `강의안_이전버전`: 이전 강의안.
- `코드_최종수정본_및_강의안_이전버전`: 최신 코드와 이전 강의안.
- 위 코드 폴더의 `Chapter01`은 M1 문제, `Chapter02`는 M2 문제이며 `solution/Chapter01`, `solution/Chapter02`에 정답이 있다고 안내됨.

## 강의 운영에 반영할 피드백

- 과거 환경설정에 1일차 약 90분, 3일차 약 60분이 소요됐다. 먼저 끝낸 수강생용 선행 자료·추가 과제를 준비할 필요가 있다.
- M1 비개발자와 M2 숙련자의 격차가 크므로 챕터와 캡스톤 진행 속도를 개인·팀 수준에 맞춰 조절할 필요가 있다.
- M2 중간에 M1 핵심 개념을 다시 확인하는 구간이 필요하다.
- Git 사용에 익숙하지 않은 수강생을 위해 사내 저장소에서 코드를 받는 절차를 안내해야 한다.
- 9차수 M2에서는 교안 밖 심화 질문에 대한 대응과 풀이 지원이 부족했다는 피드백이 있었다.
