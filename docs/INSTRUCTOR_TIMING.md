# 강사용 시간 배분

이 문서는 학습자용 노트북의 의미 번호에 시간을 연결하는 강사용 운영표다. 노트북 제목과 본문에는 진행 분·시각을 넣지 않는다. 2026-09-03 커리큘럼 수정본의 블록 총시간은 유지하되 세부 주제 배정은 교안 제작안이므로 실제 진행 속도에 맞춰 조정한다.

수업은 08:30~17:30이며 점심 1시간을 제외한 순수 수업 시간은 매일 480분이다. 점심·휴식 시각은 확인되지 않아 정하지 않았다.
