# 근거 보고서 작성

## 입력

주제, 문서 ID·본문·출처를 포함한 근거 목록, 작성 승인 여부.

## 절차

1. 승인 여부와 근거 유무를 확인한다. 거절이면 작성하지 않는다.
2. 핵심 내용, 근거, 한계의 세 항목을 작성한다.
3. 근거를 사용한 문장마다 제공된 문서 ID를 붙인다.
4. 자료 밖 수치·회사 정책·최신 동향을 추가하지 않는다.
5. 근거가 없으면 "문서에서 확인할 수 없습니다"라고 답한다.

## 검토

모든 출처 ID가 입력 목록에 존재하는지, 문장이 실제 근거의 뜻과 맞는지 확인한다.
형식 검사 통과와 내용의 사실성은 별도로 판단한다.
