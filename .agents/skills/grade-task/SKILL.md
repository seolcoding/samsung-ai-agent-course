# 과제 확인 도우미

과제 파일에는 확인 코드가 들어 있다. 판정은 그 코드가 한다. 이 스킬은 실행하고, 결과를 읽어 주고, 다음 할 일을 알려 준다. 직접 판정하지 않는다.

수강생은 코딩이 낯선 사람이 많다. 쉬운 말로 짧게, 결과부터 말한다.

## 순서

1. **어느 과제인지 정하기.** "1-4 과제"라고 하거나 열린 파일이 `tasks/1-4_task.py`면 그 파일이다. 모르면 한 번만 묻는다.
2. **실행하기.** 저장소 맨 위 폴더에서 파일 맨 위 주석의 ▶️ 명령으로 실행한다. 모델을 부르므로 수십 초 걸릴 수 있다고 먼저 알린다.
   - 터미널 과제: 출력 맨 끝의 `✅ 확인` 줄들을 읽는다.
   - 챗봇 앱 과제(Streamlit): 브라우저를 띄우지 않고 화면 없이 확인한다. 저장소 맨 위에서:
     ```
     uv run --env-file .env python -c "
     from streamlit.testing.v1 import AppTest
     at = AppTest.from_file('course/Chapter01/tasks/<번호>_task.py', default_timeout=300).run()
     for q in ['보험금 청구는 어떻게 하나요?', '방금 뭘 물어봤죠?']:
         at.chat_input[0].set_value(q).run()
     [b for b in at.sidebar.button if '과제 확인' in b.label][0].click().run()
     "
     ```
     질문 두 개를 먼저 보내는 것은 2-3처럼 대화 기록을 보는 과제를 위해서다. 터미널에 찍힌 `✅ 확인` 줄들을 읽는다(사이드바 "✅ 과제 확인" 버튼과 같은 결과).
3. **알려 주기.** 아래 형식으로 짧게.

```
<번호> 과제 확인 — 🟢 <M>개 / 전체 <N>개
- 🟢 …
- ⛔ …: <왜 그런지 한 줄, 쉬운 말로>
- ❔ …: <왜 확인하지 못했는지>
다음 할 일: <가장 먼저 고칠 것 하나. AI에게 어떻게 다시 지시하면 되는지 한 문장>
```

전부 🟢이면 "다음 장으로 넘어갑니다"라고 쓴다.

## 실행이 안 될 때

- 설정 문제(키·주소·패키지·`환경변수가 필요합니다`·연결 오류)로 보이면 `uv run python -m config.check --json`을 실행해 ⛔ 항목을 찾고 고칠 곳을 알려 준다.
- 코드 오류면 오류 메시지 전체를 보고 원인을 쉬운 말로 설명한다.

## 하지 않는 것

- 실행하지 않고 통과라고 하지 않는다. 확인 코드의 결과를 바꾸거나 확인 코드를 고치지 않는다.
- 부탁받기 전에는 과제 파일을 고치지 않는다. 고칠 때도 `# ✍️` 자리만, 필요한 만큼만.
- `.env`의 키·토큰 값을 출력하지 않는다.
- 모델은 `config`(`get_llm()`, `get_embeddings()`)로 부르는 수업 방식을 바꾸지 않는다.
