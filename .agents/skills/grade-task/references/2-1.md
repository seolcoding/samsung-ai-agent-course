# 2-1 과제: 도구 두 개를 쓰는 그래프 Agent

- 과제 파일: `course/Chapter01/notebooks/2-1_task.py`
- 실행 명령(저장소 맨 위에서): `uv run --env-file .env python course/Chapter01/notebooks/2-1_task.py`

## 목표

환율 도구와 날씨 도구를 가진 LangGraph Agent를 만듭니다. agent 노드가 도구를 쓸지 판단하고, ToolNode가 실행한 뒤 agent로 돌아오는 반복을 그래프로 잇고, 질문 두 개를 실행합니다.

## 들어갈 것

- `@tool`로 환율 도구(고정 환율)와 날씨 도구(고정 날씨)를 만듭니다
- State는 `messages` 하나이고, agent 노드는 도구가 연결된 LLM을 호출합니다
- agent → (`tools_condition`) → tools → agent로 잇고, 그래프 모양을 `print(app.get_graph().draw_ascii())`로 출력합니다
- 환율 질문과 날씨 질문을 실행하고, 결과는 `results = tool_graph_result["messages"]`처럼 꺼내 `for m in results: m.pretty_print()`로 출력합니다

## 성공 기준과 확인 방법

1. 🟢 두 질문 모두 `Tool Message` 칸이 나온다
   - 확인: 출력에 질문마다 `Tool Message` 칸이 있다
2. 🟢 마지막 `Ai Message`에 도구가 돌려준 값이 들어 있다
   - 확인: 질문마다 마지막 `Ai Message`의 값이 바로 위 `Tool Message`의 내용(환율로 계산한 금액, 날씨)과 맞다
3. 🟢 그래프 그림에 agent와 tools가 서로 오가는 길이 보인다
   - 확인: `draw_ascii()` 출력에 `agent`와 `tools` 노드가 있고, 코드에 tools에서 agent로 돌아가는 `add_edge("tools", "agent")`와 agent 뒤의 `tools_condition` 갈림길이 있다(글자 그림만으로는 돌아오는 선이 겹쳐 보일 수 있다)

## 확인 질문

`tools_condition`은 무엇을 보고 다음 노드를 정하나요?

1. 질문에 숫자가 들어 있는지
2. 마지막 AI 메시지에 도구 호출(`tool_calls`)이 있는지
3. 도구가 몇 개 연결되어 있는지
4. 그래프를 몇 번 돌았는지

정답: 2

해설:
- 1: 질문의 글자를 보지 않습니다.
- 2: 마지막 AI 메시지에 도구 호출이 있으면 tools로, 없으면 끝으로 보냅니다.
- 3: 연결된 도구 수와는 관계가 없습니다.
- 4: 반복 횟수는 보지 않습니다. 횟수 제한은 따로 정합니다.
