# 3-3 과제: 번역 Agent를 A2A로 띄우고 불러 보기

- 과제 파일: `course/Chapter02/tasks/3-3/3-3_task.py`
- 실행 명령(저장소 맨 위에서): `uv run --env-file .env python course/Chapter02/tasks/3-3/3-3_task.py`

## 목표

한국어 문장을 영어로 옮기는 Translator Agent를 A2A 서버로 만들고, 같은 파일의 클라이언트가 카드를 읽은 뒤 번역을 한 번 맡깁니다. 서버는 파일 맨 아래 고정 코드가 빈 포트(`PORT`)에 잠깐 띄웠다가 끕니다. 수강생은 `# ✍️ 목표 1~3` 자리만 채웁니다.

## 시작 상태와 실행할 때 알아 둘 것

- 시작 상태: `agent_card = None`, `app = None`이 그대로이고, `call_translator`가 `(목표 3: 아직 비어 있습니다 …)`만 출력한다. 실행하면 `(목표 1: …)`, `(목표 2: …)` 줄만 나오고 끝난다.
- 정상 출력 순서: `[만든 카드]` → `[서버] http://127.0.0.1:<포트> 에 잠깐 띄웠습니다.` → 카드에서 읽은 이름·스킬 → 보낸 문장 → 번역 결과 → `[서버] 껐습니다(포트 <포트>).` 클라이언트 쪽 출력 문구는 수강생마다 달라도 된다.
- a2a 라이브러리의 `Dispatcher task is not running. Cannot wait for event dispatch.` 줄과 `DeprecationWarning` 줄은 정상이다.
- 실행이 60초 넘게 끝나지 않으면 멈추고, 서버를 끄는 고정 코드(맨 아래 `main()`)를 바꾸지 않았는지 본다. 바꿨으면 원래대로 되돌리라고 안내한다.
- 맨 아래 "고치지 않습니다" 부분(`main()`, `asyncio.run(main())`)과 `PORT`·`URL`·`HEADERS` 줄이 시작 파일과 같아야 한다. 다르면 해당 기준을 판정하기 전에 되돌리라고 안내한다.

## 학습 목표(채점 기준)와 확인 방법

1. 🟢 `t.AgentCard`와 `t.AgentSkill`로 Agent Card를 만들 수 있다
   - 확인: 출력의 `[만든 카드]` 줄에 이름 `Translator Agent`와 번역 스킬 이름 하나가 있다. 코드에서 `agent_card`가 `t.AgentCard(...)`이고 `skills=[t.AgentSkill(...)]`에 Skill이 하나 이상 있으며, `supported_interfaces`의 주소가 `URL`이다(`localhost:8001`처럼 다른 주소를 적으면 ⛔: 카드가 이 서버를 가리키지 않는다)
2. 🟢 `AgentExecutor`에서 Agent 결과를 `t.Message`로 `EventQueue`에 내보내는 서버를 Starlette 앱으로 조립할 수 있다
   - 확인: 출력에 `[서버] … 띄웠습니다`와 `[서버] 껐습니다`가 있고, 서버 쪽 오류(Traceback이 `execute` 안이나 `Starlette`·`DefaultRequestHandlerV2` 줄을 가리킴)가 없다. 클라이언트 쪽 오류로 번역 결과가 나오지 않았으면 이 기준은 코드로 판정한다. 코드에서 `AgentExecutor`를 상속한 클래스의 `execute`가 받은 글(`context.get_user_input()`)로 `llm`을 부르고, 그 결과를 `event_queue.enqueue_event(t.Message(role=t.Role.ROLE_AGENT, parts=[t.Part(text=...)], ...))`로 내보낸다. `DefaultRequestHandlerV2`에 이 Executor·TaskStore·카드를 넣고, `create_agent_card_routes`와 `create_jsonrpc_routes`로 만든 라우트를 `Starlette(routes=...)`에 담아 `app`에 넣었다. 번역하지 않고 받은 글을 그대로 돌려주면 ⛔
3. 🟢 `A2ACardResolver`로 카드를 읽고 메시지를 보내 응답 텍스트를 출력할 수 있다
   - 확인: 출력에 카드에서 읽은 이름 `Translator Agent`·스킬 이름과, 회의가 오후 3시에 시작한다는 뜻의 영어 문장이 있다. 코드에서 `call_translator`가 `A2ACardResolver(..., URL).get_agent_card()`로 카드를 읽고, `t.SendMessageRequest`를 `client.send_message(...)`로 보내 응답 `parts`의 글을 출력한다. 클라이언트에서 `llm`을 직접 불러 번역하거나 `agent_card` 변수를 그대로 찍으면 ⛔(A2A를 거치지 않는다)
   - 자주 나는 오류: `VersionNotSupportedError: A2A version '0.3'`은 `httpx.AsyncClient`에 `HEADERS`를 붙이지 않은 것이다(⛔, 다음 할 일은 헤더 붙이기)
   - 함께 확인: 실행이 Ctrl+C 없이 끝나고, 끝난 직후 `uv run python -c "import socket; print(socket.socket().connect_ex(('127.0.0.1', <출력의 포트>)))"`가 0이 아닌 값을 출력한다(0이면 서버가 남아 있다)

## 확인 질문

Translator Agent의 안쪽을 `llm` 한 번 호출에서 LangGraph 그래프로 바꿨습니다. 카드와 메시지 형식은 그대로입니다. 클라이언트 코드는 어떻게 해야 하나요?

1. 그래프를 부르도록 클라이언트도 고쳐야 합니다
2. 카드의 Skill 이름을 그래프 노드 이름으로 바꿔야 합니다
3. 고치지 않아도 됩니다. 카드와 메시지 형식만 맞으면 그대로 맡길 수 있습니다
4. 서버 포트를 바꿔야 새 그래프가 연결됩니다

정답: 3

해설:
- 1: 클라이언트는 서버 안을 부르지 않고 A2A 메시지만 보냅니다.
- 2: 카드에는 내부 구현을 적지 않습니다. 노드 이름은 밖에서 몰라도 됩니다.
- 3: 맡기는 쪽은 상대의 내부 구현을 몰라도 됩니다. 바뀐 것은 AgentExecutor 안쪽뿐입니다.
- 4: 포트는 연결 주소일 뿐입니다. 안쪽 구현이 바뀌어도 주소는 그대로 써도 됩니다.
