# 4-1 과제: 회의록 요약 스킬을 쓰는 Deep Agent

빌드 산출물이다(dev/builders/build_lab.py). 직접 고치지 않는다.

- 과제 파일: `course/Chapter02/notebooks/4-1_task.py`
- 실행 명령(저장소 맨 위에서): `uv run --env-file .env python course/Chapter02/notebooks/4-1_task.py`

## 목표

과제 파일이 회의록 요약용 SKILL.md를 직접 쓰고, 그 스킬과 회의록 도구를 가진 Deep Agent를 만듭니다. 회의록 요약 요청은 스킬의 양식대로 답하고 범위 밖 요청은 거절하는지, 요청 두 개로 확인합니다.

## 들어갈 것

- 과제 파일이 실행될 때 바로 옆 `harness/task/skills/meeting-summary/SKILL.md`를 씁니다. 맨 위 `---` 사이에 `name: meeting-summary`와 언제 쓰는지 적은 `description`을 넣고, 본문에는 답을 `[회의 요약]` 줄로 시작해 `결정 사항`과 `할 일(담당자)` 두 칸으로 쓰라는 양식을 적습니다
- `@tool`로 회의록 도구 `get_meeting_notes`를 만듭니다. 정해 둔 회의록 글(결정 사항 하나, 담당자가 있는 할 일 둘)을 돌려줍니다
- `create_deep_agent`에 `model=llm`, 회의록 도구, `FilesystemBackend(root_dir=<harness/task 폴더>, virtual_mode=True)`, `skills=["skills/"]`, 범위 밖 요청을 거절하는 `system_prompt`, `MemorySaver()`를 넣습니다. 폴더 경로는 `Path(__file__).parent`를 기준으로 정합니다
- 요청 "주간 회의 회의록을 가져와서 요약해 줘."와 "파이썬으로 피보나치 코드를 짜 줘."를 서로 다른 `thread_id`로 실행합니다. 결과는 `results = deep_agent_result["messages"]`처럼 꺼내 `for m in results: m.pretty_print()`로 출력합니다

## 성공 기준과 확인 방법

1. 🟢 요청 1에서 Agent가 SKILL.md를 읽는다(`Tool Message` 칸에 `name: meeting-summary`가 보인다)
   - 확인: 요청 1 출력에 `read_file` 도구 호출과 `name: meeting-summary`가 든 `Tool Message`가 있다. 파일 `course/Chapter02/notebooks/harness/task/skills/meeting-summary/SKILL.md`가 있고, 코드의 `skills` 값이 SKILL.md가 든 폴더가 아니라 그 상위 폴더(`skills/`)다
2. 🟢 요청 1의 마지막 `Ai Message`가 `[회의 요약]`으로 시작하고, 회의록 도구가 돌려준 할 일과 담당자가 들어 있다
   - 확인: 요청 1에 `get_meeting_notes`의 `Tool Message`가 있고, 마지막 `Ai Message`의 첫 줄이 `[회의 요약]`이며 그 `Tool Message`에 나온 담당자 이름이 들어 있다
3. 🟢 요청 2(피보나치)는 코드 없이 거절한다
   - 확인: 요청 2의 마지막 `Ai Message`에 코드(`def` 등)가 없고 거절하는 말이 있다. 코드의 `system_prompt`에 범위 밖 요청을 거절하라는 말이 있다

## 확인 질문

Agent가 대화를 시작할 때 스킬마다 먼저 보는 것은 무엇인가요?

1. SKILL.md 파일 전체
2. 스킬 폴더의 이름만
3. 맨 위의 `name`과 `description`
4. 본문의 양식만

정답: 3

해설:
- 1: 처음부터 전체를 읽지 않습니다. 필요하다고 판단한 스킬만 `read_file`로 전체를 읽습니다.
- 2: 폴더 이름만으로 고르지 않습니다. `name`은 폴더 이름과 같아야 하고, 고르는 근거는 `description`입니다.
- 3: 이름과 설명만 먼저 보고, 지금 요청에 맞는 스킬이면 파일 전체를 읽어 절차를 따릅니다. 그래서 `description`에 언제 쓰는지를 적습니다.
- 4: 본문은 스킬을 쓰기로 정한 뒤에 읽습니다.
