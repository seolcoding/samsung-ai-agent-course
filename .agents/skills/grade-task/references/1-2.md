# 1-2 과제: IT 헬프데스크 상담 스크립트

빌드 산출물이다(dev/builders/build_lab.py). 직접 고치지 않는다.

- 과제 파일: `course/Chapter01/notebooks/1-2_task.py`
- 실행 명령(저장소 맨 위에서): `uv run --env-file .env python course/Chapter01/notebooks/1-2_task.py`

## 목표

IT 헬프데스크 상담원 역할을 맡은 모델과 두 번 이어서 대화하는 스크립트를 만듭니다. 두 번째 질문은 첫 답을 가리키고("방금 말한 첫 번째 방법을 더 자세히"), 마지막 답은 조각으로 받아 이어 붙여 출력합니다.

## 들어갈 것

- system 메시지로 역할(친절한 IT 헬프데스크 상담원)을 정합니다
- 첫 질문(예: 노트북이 느려요)을 보내고 답을 출력합니다
- 앞 질문과 답을 메시지 목록에 쌓은 채로 두 번째 질문 "방금 말한 첫 번째 방법을 더 자세히 알려 줘"를 보냅니다
- 두 번째 답은 `stream()`으로 조각을 받아 이어 붙여 출력합니다

## 성공 기준과 확인 방법

1. 🟢 첫 질문과 그 답이 출력된다
   - 확인: 출력에 첫 질문에 대한 답 문장이 있다
2. 🟢 두 번째 답이 첫 답의 첫 번째 방법을 이어서 자세히 설명한다
   - 확인: 코드에서 두 번째 호출의 메시지 목록에 첫 질문과 첫 답이 들어 있고, 출력의 두 번째 답이 첫 답에서 처음 든 방법을 자세히 설명한다(이전 대화를 모른다고 하면 ⛔)
3. 🟢 두 번째 답이 조각으로 받아 출력된다
   - 확인: 코드에 `.stream(`이 있고 조각마다 출력한다(`end=""`로 이어 붙이지 않아도 조각을 받아 출력하면 🟢)

## 확인 질문

모델이 두 번째 질문에서 첫 답을 기억하게 하려면 어떻게 해야 하나요?

1. 두 번째 호출 때 앞 질문과 답을 메시지 목록에 함께 넣어 보낸다
2. 같은 `llm` 객체로 부르면 모델이 앞 대화를 알아서 기억한다
3. temperature를 0으로 낮춘다
4. 두 번째 질문을 system 메시지로 보낸다

정답: 1

해설:
- 1: 모델은 호출마다 받은 메시지만 봅니다. 앞 대화를 다시 넣어 보내야 이어서 답합니다.
- 2: 모델은 앞 호출을 기억하지 않습니다. 객체가 같아도 매번 새로 시작합니다.
- 3: temperature는 답의 다양성을 정할 뿐, 앞 대화를 넣어 주지 않습니다.
- 4: system 메시지는 역할 지시입니다. 앞 대화를 넣는 방법이 아닙니다.
