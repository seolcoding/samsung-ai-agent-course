# 1-2 과제: requests와 SDK로 LLM 부르기

- 과제 파일: `course/Chapter01/tasks/1-2/1-2_task.py`
- 실행 명령(저장소 맨 위에서): `uv run --env-file .env python course/Chapter01/tasks/1-2/1-2_task.py`
- 시작 상태: 두 자리 모두 `print("(아직 작성하지 않았습니다)")`만 있다. 맨 위 설정 부분(주소·헤더·`client`·`PAYLOAD_EXTRA`)은 처음부터 있던 것이니 채점 대상이 아니다.

## 학습 목표와 확인 방법

1. `requests`로 HTTP 요청을 직접 보내 LLM 답(`choices[0].message.content`)을 꺼낼 수 있다
   - 확인: 코드에 `requests.post(`가 있고 주소가 `api_base_url`로 만든 `…/chat/completions`이며, `json=`에 `model`과 `messages`(role·content가 있는 목록)가 들어 있다. 응답 JSON에서 `["choices"][0]["message"]["content"]`를 꺼내 출력한다. 실행 출력의 `=== 1. requests로 직접 보내기 ===` 아래에 질문(노트북이 느려짐)에 대한 답 문장이 나온다. JSON 전체(`{'id': …, 'choices': …}`)만 출력하고 답 문장을 꺼내지 않았으면 ⛔. `openai`의 `client`나 `get_llm()`으로 보냈으면 ⛔(직접 HTTP 요청이 목표)
2. SDK(`client.responses.create`)로 developer·user 메시지를 보내 `output_text`로 답을 받을 수 있다
   - 확인: 코드에 `client.responses.create(`가 있고 `input`에 `"role": "developer"` 메시지와 `"role": "user"` 메시지(QUESTION)가 들어 있으며, `.output_text`를 출력한다. 실행 출력의 `=== 2. SDK로 보내기 ===` 아래에 답 문장이 나온다(두 문장 안팎이면 developer 지시가 들어간 것이다. 길이는 판정에 쓰지 않는다). `client.chat.completions.create`로 바꿔 썼으면 답이 나와도 ⛔(수업에서 쓴 SDK 방식이 아니다). developer 메시지 없이 문자열만 넘겼으면 ⛔

## 확인 질문

`requests`로 받은 응답 JSON에서 답 문장은 어디에 있었나요?

1. `recv_json["output_text"]`
2. `recv_json["choices"][0]["message"]["content"]`
3. `recv_json["messages"][-1]`
4. `recv_json.content`

정답: 2

해설:
- 1: `output_text`는 SDK의 Responses API 응답 객체가 주는 속성입니다. `/chat/completions` JSON에는 없습니다.
- 2: Chat Completions 응답은 후보 목록 `choices`의 첫 항목 안 `message.content`에 답 문장이 있습니다.
- 3: `messages`는 우리가 보낸 요청에 넣은 칸입니다. 응답 JSON에는 없습니다.
- 4: `.json()`이 돌려준 것은 파이썬 사전(dict)이라 `.content` 속성이 없습니다. `AttributeError`가 납니다.
