# AI Agent 개발 과정 — 수강생 자료

수업은 `ChapterNN/notebooks/`의 노트북으로 진행합니다. 강의 노트북(`_LEC`)으로 개념을 보고, 실습 노트북(`_LAB`)으로 직접 실행합니다. 1·2일차 `_LAB`은 완성된 코드를 실행하고 값을 바꿔 보는 실습이고, 3·4일차 `_LAB`은 보기를 골라 주석을 풀어 코드를 완성하는 실습입니다. 각 실습 노트북 맨 끝의 과제는 노트북 밖 `ChapterNN/tasks/<번호>_task.py` 파일 하나를 AI와 함께 완성하는 것입니다.

**브랜치:** 이 저장소의 `main` 브랜치만 받아서 실습합니다. `dev` 브랜치는 강사용 자료라 받지 않습니다.

## 처음 한 번: 설치

저장소 맨 위 폴더(이 `course/` 폴더의 위)에서 실행합니다.

1. `uv`를 설치합니다.
2. 필요한 패키지를 설치합니다.

   ```
   uv sync --extra notebooks
   ```

3. `.env.sample`을 복사해 저장소 맨 위에 `.env`를 만들고, 강사가 알려 준 값을 채웁니다. `.env`의 키는 다른 사람에게 보이거나 파일로 올리지 않습니다.

4. `.env` 맨 위 `COURSE_ENV`를 고릅니다. 강의장 PC는 `samsung`(사내), 사내망 밖은 `out`(사외)입니다.
5. 설정을 점검합니다. "준비 완료"가 나오면 됩니다.

   ```
   uv run python -m config.check
   ```

설치나 실행이 안 되면 `agent_docs/troubleshooting.md`를 봅니다.

## 수업 때

1. VS Code에서 저장소 폴더를 엽니다.
2. `course/Chapter01/notebooks/`(2부는 `course/Chapter02/notebooks/`)에서 노트북을 엽니다. 커널은 저장소의 `.venv`를 고릅니다.
3. 셀은 위에서부터 차례로 실행합니다.
4. 슬라이드가 보이지 않으면 바로 위 셀을 다시 실행합니다. 그래도 안 되면 맨 위 셀부터 다시 실행합니다.

## 실습 노트북 보는 법

- `# ✍️ CHANGE_HERE:` 셀은 먼저 그대로 실행합니다. 셀 위의 **바꿔 볼 값**을 복사해 바로 아래 줄의 표시된 자리에 붙여 넣고 다시 실행합니다. 셀 아래 접힌 "무슨 일이 생기나"와 비교한 뒤 원래 값으로 되돌립니다.
- 3·4일차: `# ✅ CHOOSE_HERE:` 아래 보기 중 하나를 골라 같은 번호의 줄을 모두 선택하고 `Ctrl + /`로 주석을 푼 뒤 실행합니다. 실행한 뒤 성공 기준과 비교합니다. 🟢는 되어야 하는 것, ⛔는 다시 해야 하는 신호입니다. 그다음 접힌 "정답 보기"의 해설을 읽습니다.
- 실습마다 과제 파일 `ChapterNN/tasks/<번호>_task.py`가 하나 있습니다. `✍️` 자리를 `✨` 힌트를 보고 AI와 함께 채우고, 파일 맨 위 ▶️ 명령으로 실행하면 끝에 ✅ 확인(🟢/⛔)이 나옵니다(챗봇 앱은 사이드바 "✅ 과제 확인" 버튼). 막히면 AI에게 "<번호> 과제 확인해 줘"라고 합니다.
