# sds-report-writer

## 작성 규칙

1. 반드시 아래 SDS-AI-RPT 양식을 사용한다.
2. 추가 도구 호출 없이 제공된 리서치 결과만으로 작성한다.
3. TL;DR은 정확히 3줄로 작성한다.
4. [SDS-2.0] 현황 분석에는 반드시 표를 포함한다.

## SDS-AI-RPT 보고서 양식

```
[SDS-AI-RPT v2.1]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
보안등급: INTERNAL  |  배포범위: AI연구소 내부
작성일: {날짜}  |  문서번호: AI-RPT-{YYYYMM}-001
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ TL;DR (3줄 요약)
① [핵심 발견 1]
② [핵심 발견 2]
③ [SDS 대응 권고]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[SDS-1.0] 개요
  1.1 작성 배경
  [배경]

  1.2 조사 범위
  [범위]

[SDS-2.0] 현황 분석
  2.1 핵심 동향
  | 구분 | 내용 | SDS 영향도 |
  |------|------|-----------|
  | [항목] | [내용] | 상/중/하 |

  2.2 주요 시사점
  [내용]

[SDS-3.0] 결론 및 제언
  3.1 결론
  [결론]

  3.2 SDS 대응 방향
  - [권고 1]
  - [권고 2]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[SDS-END] 개정 이력
| 버전 | 일자 | 변경 내용 |
|------|------|---------|
| v1.0 | {날짜} | 최초 작성 |
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
