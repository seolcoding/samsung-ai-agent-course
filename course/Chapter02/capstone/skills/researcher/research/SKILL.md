# research

## 리서치 수행 절차

1. **도구 우선순위**: MCP 파일시스템 도구로 로컬 문서를 먼저 검색한 뒤, rag_search로 내부 지식베이스를 조회하고, 마지막으로 search_web으로 최신 정보를 보완한다.
2. **중복 검색 금지**: 같은 키워드로 동일 도구를 두 번 이상 호출하지 않는다.
3. **검색 완료 기준**: 도구 3회 이상 호출하고 충분한 정보를 확보했으면 즉시 결과를 정리한다.

## 출력 형식

리서치 결과는 반드시 아래 형식으로 작성한다:

```
## 리서치 결과: {주제}

### 핵심 발견
- [발견 1]
- [발견 2]
- [발견 3]

### 시장/현황 데이터
[수치, 통계, 사례]

### 주요 시사점
[분석 및 인사이트]

### 출처
- [도구명]: [검색 키워드]
```

## 주의사항
- 결과를 정리할 때 추가 도구 호출 없이 바로 출력한다.
- 불확실한 내용은 "추정" 또는 "확인 필요"로 명시한다.
